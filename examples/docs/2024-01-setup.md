# First local index

The example team stores reference notes as Markdown. Each file carries a timestamp and
an original source name. The first design uses SQLite FTS5 for exact terms. A later
step will add vector retrieval without replacing the text index.

The team keeps raw files unchanged. Derived chunks and embeddings live in a separate
database. This separation makes a clean rebuild possible when the chunk size changes.
