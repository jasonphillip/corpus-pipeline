# Onboarding: Development Environment

Synthetic document, Larkspur Systems wiki (fictional).

Use this page to run a local copy of the telemetry stack on your laptop. The local stack includes the ingest gateway, the queue broker, a decoder worker, a time-series store and the dashboard. It uses recorded frames, so no radio hardware is needed.

## Requirements

- Python 3.12 for the tools and the decoder.
- Docker with at least 8 GiB of memory for the containers.
- 20 GB of free disk space.
- The `lsctl` tool, installed with `pipx install larkspur-lsctl`.

## Start the stack

1. Clone the `platform` repository.
2. Run `make devstack`. The first run pulls images and takes about 10 minutes.
3. Run `make devstack-seed` to load 3 days of sample frames.
4. Open the dashboard at `http://localhost:13080`.

## Ports

The dev stack adds 10000 to every service port, so the ingest gateway listens on 18443. This avoids clashes with other tools on your laptop. The dashboard port 3080 becomes 13080. The queue broker port 6710 becomes 16710. The time-series store port 8812 becomes 18812.

The dev gateway uses a self-signed certificate. Set `LARKSPUR_DEV_CA=1` so that `lsctl` and the client libraries trust it.

## Sample data

The seed data holds 40 sample flights from three simulated sites. The frames are generated by a script and contain no real flight data. To replay a flight into the stack, run `make replay FLIGHT=F-SAMPLE-0001`.

## Tests

- `make test` runs unit tests. It takes about 2 minutes.
- `make test-integration` starts the stack and sends frames through it. It takes about 8 minutes.
- `make lint` runs the formatter and the type checker.

CI runs the same commands. A pull request needs a green CI run and one review.

## Debugging a decoder

Run the decoder outside Docker with `python -m larkspur.decoder --config dev/decoder.toml`. The config keys are the same as in production. Set `crc_mode = "repair"` in the dev file when you test damaged frames.

## Common problems

- Port already in use: stop the old stack with `make devstack-down`.
- The queue broker exits at once: Docker has too little memory. Raise the limit to 8 GiB.
- Tests fail on time zones: set `TZ=UTC`. All code assumes UTC.

## Cleaning up

Run `make devstack-clean` to remove containers and volumes. This frees about 6 GB.
